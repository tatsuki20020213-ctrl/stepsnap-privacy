StepSnap プライバシーポリシー

最終更新日：2026年10月24日

StepSnap（以下「本拡張機能」）は、社内の業務手順書を作成するための Chrome 拡張機能です。本拡張機能が扱う情報と、その取り扱いについて説明します。

1. 扱う情報

本拡張機能は、ユーザーが「記録を開始」を押してから「終了」を押すまでの間（一時停止中を除く）に、次の情報を記録します。

  • ブラウザでの操作：クリックした位置、クリックした項目の名前（ボタンやリンクの文字など）、入力欄に入力したこと、選択肢で選んだ項目の名前
    • 入力欄に入力した文字そのものは記録しません（「〇〇に入力」とだけ記録します）。
  • 画面の画像：操作したときの、表示中のタブの画面の画像
  • ページの情報：操作したページのタイトルと URL
  • ブラウザ以外の画面の画像：ユーザーが記録の開始時に画面の共有を許可した場合に限り、ショートカットキーを押したときの画面の画像
  • ブラウザ以外でのクリック（Windows のみ）：ユーザーが設定で「Chrome の外のクリックも自動で撮る」をオンにし、利用する組織が配布する Windows 用の補助アプリ「StepSnap Helper」（以下「補助アプリ」）を入れている場合に限ります。Chrome の外で左クリックしたときの位置、押した項目の名前（ボタンの文字など。取れたときだけ）、そのアプリの名前と、クリックしたモニターの画面の画像を記録します。ショートカットキーを押したときは、そのときの画面の画像を記録します。
    • キーボードで入力した内容は見ません。補助アプリが見るのは、マウスの左ボタンを押したことだけです。
  • 話した内容を文字にしたもの：ユーザーが「音声も記録する」をオンにした場合に限ります。音声そのものは保存しません。

また、ユーザーがサイドパネルで入力した手順書の内容（タイトル、概要、必要なもの、各ステップのタイトル・説明・URL とその表示名、手で追加したステップ、ユーザーがファイルから選んだり貼り付けたりして差し替えた画像、画像に付けた赤丸・文字・ぼかしなどの書き込み）と、設定画面で入力した情報（出力先の Google Apps Script の URL、作成者名、音声も記録するか、Chrome の外のクリックも撮るか）、画面の設定（前回選んだ出力形式や色など）、今開いている手順書が保存済みかどうかを保存します。

2. 保存する場所

記録した情報と設定は、ユーザーのパソコンの Chrome の中（本拡張機能の保存領域）に保存します。開発者のサーバーなどに送信することはありません。ユーザーが「保存」または出力を押したときだけ、次の「3. 送信する先」のとおり、利用する組織の Google ドライブにも保存します。

補助アプリは、うまく動かないときに確かめるための記録ファイル（StepSnapHelper.log）を、補助アプリのフォルダの中に作ります。書くのは、起動と終了の時刻、拡張機能からの命令、クリックしたアプリのファイル名（EXCEL.EXE など）、処理にかかった時間、画像の大きさ、押した項目の名前が取れたかどうかと項目の種類、使っているメモリの量だけです。押した項目の名前、ウィンドウの題名、画面の画像は書きません。このファイルはどこにも送りません。

3. 送信する先

  • 手順書の出力（Google ドキュメント・Google スライド・Notion・Word・PDF）：ユーザーが出力ボタンを押したときに限り、手順書の内容（タイトル、作成者名、概要、必要なもの、各ステップのタイトル・説明・ページのタイトルと URL・画面の画像）を、ユーザーが設定した Google Apps Script のウェブアプリ（本拡張機能を利用する組織が、自身の Google Workspace の中で管理しているもの）に送信します。
    • Google ドキュメント・Google スライドを選んだ場合は、その組織の Google ドライブに保存されます。
    • Notion を選んだ場合は、そのウェブアプリから、組織が設定した Notion のワークスペースに送られ、データベースの1行として保存されます。Notion での取り扱いには、Notion のプライバシーポリシーが適用されます。
    • Word・PDF を選んだ場合は、そのウェブアプリで変換したファイルを受け取り、ユーザーのパソコンに保存します。変換のために一時的に作った Google ドキュメント・Google スライドは、すぐにごみ箱に移します。
  • 手順書の保存（「保存」と「手順書の一覧」）：ユーザーが「保存」または出力を押したときに限り、後から開いて直せるよう、手順書の内容（上の項目に加え、書き込みを付ける前の元の画面の画像と、赤丸・文字・ぼかしなどの書き込み）を、同じウェブアプリを通して、その組織の Google ドライブの保存先フォルダに保存します。保存した人の Google アカウントのメールアドレスと作成者名、保存した日時も一緒に保存します。
    • 保存した手順書は、その組織で本拡張機能を使う人が一覧で見て、開いて直したり、削除したりできます。開いたときは、内容をこのパソコンの Chrome の中に読み込みます。
    • ぼかしは書き込みとして保存するため、保存先のフォルダを見られる人は、ぼかしを付ける前の元の画像を見ることができます。
  • HTML の保存：HTML を選んだ場合は、本拡張機能の中で作成し、ユーザーのパソコンに保存します（組織の Google Apps Script を設定している場合は、上の「手順書の保存」も行います）。
  • 補助アプリとのやり取り：本拡張機能と補助アプリは、Chrome のネイティブメッセージングを使って、ユーザーのパソコンの中だけでやり取りします。補助アプリは、Chrome の外のクリックも撮る設定で記録を始めたときに起動し、記録を終えると終了します。補助アプリはインターネットなど外部とは通信しません。
  • 音声の文字化：「音声も記録する」をオンにした場合は、Chrome に内蔵の音声認識機能を使います。パソコンの中で文字にできない場合、音声は Chrome によって Google のサーバーに送られ、文字にされます。この処理には Google のプライバシーポリシーが適用されます。
  • 通信はすべて HTTPS で行います。

4. 第三者への提供

本拡張機能が扱う情報を、販売したり、広告に使ったり、上記以外の第三者に提供したりすることはありません。手順書の作成以外の目的には使いません。

5. 情報の削除

  • サイドパネルの「新しい手順書」で、パソコンに保存した記録を削除できます。ステップごとに削除することも、「選択」で選んだステップをまとめて削除することもできます。
  • 組織の Google ドライブに保存した手順書は、「手順書の一覧」の削除で、ドライブのごみ箱に移ります（ごみ箱からは、30日で消えます）。
  • 本拡張機能を Chrome から削除すると、パソコンに保存した記録と設定もすべて削除されます。
  • 補助アプリは、付属の uninstall.bat で Chrome への登録を外し、補助アプリのフォルダ（記録ファイルを含む）を削除すると、何も残りません。
  • 出力した手順書は、Google ドライブのファイル・Notion のページ・パソコンのファイルとして、利用する組織の規程に従って管理されます。

6. お問い合わせ

本拡張機能についてのお問い合わせは、社内の担当者にお願いします。

7. 改定

内容を変更した場合は、このページを更新し、最終更新日を改めます。

StepSnap Privacy Policy

Last updated: October 24, 2026

StepSnap (the "Extension") is a Chrome extension for creating internal step-by-step work manuals. This policy explains what information the Extension handles and how.

1. Information the Extension handles

Only while the user is recording (from pressing "記録を開始" (Start recording) until "終了" (Stop), excluding pauses), the Extension records:

  • Browser actions: the position of each click, the name of the clicked element (such as button or link text), the fact that a text field was filled in, and the name of the option selected in a drop-down.
    • The text typed into fields is never recorded (only "Entered into [field]").
  • Screenshots: an image of the visible tab at the time of each action.
  • Page information: the title and URL of the page where the action took place.
  • Screen images outside the browser: only if the user allows screen sharing when starting a recording, an image of the screen each time the user presses the keyboard shortcut.
  • Clicks outside the browser (Windows only): only if the user turns on "Chrome の外のクリックも自動で撮る" (Also capture clicks outside Chrome) in the settings and has installed "StepSnap Helper", a small Windows helper app distributed by the organization using the Extension (the "Helper"). For each left click outside Chrome, the Extension records the click position, the name of the clicked element (such as button text, only when available), the name of the app, and an image of the monitor that was clicked. When the user presses the keyboard shortcut, an image of the screen at that time is recorded.
    • Keyboard input is never read. The Helper only detects presses of the left mouse button.
  • Transcribed speech: only if the user turns on "音声も記録する" (Record voice). Audio itself is not stored.

The Extension also stores the manual content entered by the user in the side panel (the title, overview, required items, each step's title, description, URL and its display name, steps added by hand, images the user replaced by choosing a file or pasting, and annotations such as circles, text and blur added to images), the settings entered by the user (the URL of the Google Apps Script web app used for export, the author name, whether to record voice, and whether to capture clicks outside Chrome), UI preferences (such as the last selected export format and colors), and whether the manual currently open has been saved.

2. Where information is stored

All recorded information and settings are stored inside Chrome on the user's computer (the Extension's local storage). Nothing is sent to the developer's servers. Only when the user presses "保存" (Save) or an export button, the manual is also saved to the Google Drive of the organization using the Extension, as described in section 3.

The Helper writes a log file (StepSnapHelper.log) in its own folder, for troubleshooting. It contains only start and stop times, the commands received from the Extension, the file name of the clicked app (such as EXCEL.EXE), processing times, image sizes, whether the name of the clicked element was found and the element's type, and memory usage. It never contains the names of clicked elements, window titles, or screen images. This file is never sent anywhere.

3. Where information is sent

  • Exporting a manual (Google Docs, Google Slides, Notion, Word, PDF): only when the user presses the export button, the manual content (title, author name, overview, required items, and each step's title, description, page title and URL, and screenshot) is sent to the Google Apps Script web app configured by the user (managed by the organization using the Extension within its own Google Workspace).
    • For Google Docs and Google Slides, the manual is saved to that organization's Google Drive.
    • For Notion, the web app sends the manual to the Notion workspace configured by the organization, where it is saved as a row in a database. Notion's Privacy Policy applies to its handling there.
    • For Word and PDF, the Extension receives the file converted by the web app and saves it on the user's computer. The temporary Google Doc or Google Slides presentation created for the conversion is moved to the trash immediately.
  • Saving manuals ("保存" (Save) and "手順書の一覧" (Manual list)): only when the user presses "保存" (Save) or an export button, so that the manual can be opened and edited later, the manual content (the items above, plus the original screenshots before annotation and the annotations such as circles, text and blur) is saved through the same web app to the configured folder in that organization's Google Drive, together with the Google account email address and author name of the person who saved it and the time it was saved.
    • Saved manuals can be listed, opened, edited and deleted by people in that organization who use the Extension. When a manual is opened, its content is loaded into Chrome on that computer.
    • Because blur is saved as an annotation, people who can view the folder can see the original screenshots before blur was applied.
  • Saving as HTML: for HTML, the file is created inside the Extension and saved on the user's computer (if the organization's Google Apps Script web app is configured, the manual is also saved as described above).
  • Communication with the Helper: the Extension and the Helper communicate only within the user's computer, using Chrome's native messaging. The Helper starts only when a recording starts with capturing clicks outside Chrome turned on, and exits when the recording stops. The Helper does not communicate with the internet or any other external service.
  • Speech transcription: when "音声も記録する" (Record voice) is on, the Extension uses Chrome's built-in speech recognition. If speech cannot be transcribed on the device, Chrome sends the audio to Google's servers for transcription, subject to Google's Privacy Policy.
  • All communication uses HTTPS.

4. Sharing with third parties

The Extension does not sell the information it handles, does not use it for advertising, and does not share it with any third party other than as described above. It is used only for creating manuals.

5. Deleting information

  • "新しい手順書" (New manual) in the side panel deletes the recordings stored on the computer. Steps can also be deleted one by one, or several at once with "選択" (Select).
  • Manuals saved to the organization's Google Drive are moved to the Drive trash when deleted from "手順書の一覧" (Manual list) (items in the trash are removed after 30 days).
  • Removing the Extension from Chrome deletes all recordings and settings stored on the computer.
  • The Helper leaves nothing behind once it is unregistered from Chrome with the included uninstall.bat and its folder (including the log file) is deleted.
  • Exported manuals are managed as Google Drive files, Notion pages, or files on the computer in accordance with the policies of the organization using the Extension.

6. Contact

For questions about the Extension, please contact the person in charge within your organization.

7. Changes

If this policy changes, this page will be updated along with the "Last updated" date.
